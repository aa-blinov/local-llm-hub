—

Выполните шаги по порядку. Зелёная галочка означает, что шаг готов. Ничего настраивать не нужно.

1

Установить программу для моделей

Это программа-помощник, она запускает модель на вашем Mac. Ставится один раз: около 2 ГБ, 3–5 минут.

Проверяю…
2

Выбрать и скачать модель

Модель — это сам ассистент: все его знания хранятся в ней. Скачивается один раз, занимает много места на диске.

3

Запустить ассистента

«Чат» — для обычных вопросов, запускается быстрее. «Кодинг» — для работы с программами, помнит больше текста, но требует больше памяти.

Проверяю, хватит ли памяти…
4

Спросить ассистента

Напишите вопрос и нажмите «Отправить». Ответ обычно приходит за 2–30 секунд.

Ассистент может ошибаться. Важные факты проверяйте в надёжных источниках.

Запуск

Готовый набор: «Чат» для вопросов, «Кодинг» для программ.

Проверка памяти…

Она запускает модель. MLX быстрее на Apple Silicon.

Сколько текста ассистент держит в голове. Больше — больше памяти.

Сколько текста читается за раз. Меньше — экономнее по памяти, но медленнее.

Сохраняет начало разговора на диск, чтобы не перечитывать его при каждом вопросе.
