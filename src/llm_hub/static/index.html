Install the model program

This is the program that runs models on your Mac. You install it once: about 2 GB, 3–5 minutes.

Choose and download a model

The model is the assistant itself: all its knowledge is stored in it. It downloads once and takes a lot of disk space.

3

Start the assistant

Chat is for everyday questions and starts faster. Coding is for working with programs, remembers more text and needs more memory.

Checking whether there is enough memory…
4

Ask the assistant

Type a question and press Send. An answer usually takes 2–30 seconds.

The assistant can make mistakes. Check important facts in reliable sources.
